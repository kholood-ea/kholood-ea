## 🙋‍♀️ About Me

I'm an Egypt, Cairo-based React Native engineer who builds to help people.

Five years in mobile taught me that the best work happens when you're solving 
real problems for real people. That's what drives me.

**On how I work:**  
I don't stop at "it works." I ask why before I write a single line, care deeply 
about architecture and design patterns where it makes sense, and treat code quality as a non-negotiable 
— not something to revisit when there's time (there's never time).  
I go deep. I'd rather understand something properly than move fast and paper over it.

I read about Islamic finance — not just theory, but how it shapes real financial 
decisions. It informs how I invest, how I think about products, and how I build.

If you're building something meaningful — especially for emerging markets, fintech, 
or communities that deserve better tools — I'm interested.
